## 1. Scope rule (what was NOT touched)

- The **boundary clamp** (`clampPieceToBoard`), the **tray scrollbar**, the tray's
  **3-row layout**, piece arrangement and scrolling behaviour, and all puzzle
  generation/snap/hint/edges/preview/pause/resume logic are unchanged from
  SESSION-2026-09-03.
- This session was a refinement pass, not a re-architecture. Only the four
  files below changed.

## 2. What landed

- **Jigsaw-cut preview** (`difficulty-screen.tsx` + new `jigsaw-lines.ts` +
  `jigsaw-lines.test.ts`): replaced the straight black grid lines on the Select
  Difficulty preview with a `react-native-svg` overlay of realistic **interlocking
  jigsaw cuts**. The overlay divides the photo into `dim × dim` cells for the
  selected count (e.g. 25 → 5×5, 784 → 28×28). Every internal boundary is drawn
  as a single continuous path whose tabs/slots alternate between neighbour cells
  (phase-shifted per row/column), so pieces read as interlocking. The **outer
  border stays a clean rectangle** and edge/corner pieces never grow knobs that
  poke out of the frame. Coordinates are in cell units (`viewBox="0 0 dim dim"`
  + `preserveAspectRatio="none"`), so the strokes stretch to the preview's actual
  size and regenerate whenever the selected count changes.
- **Selected count style** (`piece-picker.tsx`): the selected piece count now sits
  inside a **green rounded-square container** holding the number plus the word
  "PIECES". Unselected counts stay slim and muted on both sides. The horizontal
  carousel, snap-to-centre selection, tier caption and saved-progress pill are
  unchanged; only the selected item's count presentation changed.
- **Game header** (`game-screen.tsx`): the piece count now lives in a
  rounded-surface box on the **right** (matching the timer box on the **left**),
  both below the five round icon controls (Back, Hint, Edges, Preview, Pause).
  The **tooltip-on-tap** (state, `showTooltip`, timer, render, style) was removed
  so the controls are icon-only at all times. Puzzle title stays removed. Helper
  a11y labels on the icon buttons are preserved for accessibility.

## 3. Design notes

- The jigsaw knobs are sized in cell units (`KNOB = 0.26`, `FLAT = 0.16`), which
  keeps them proportional on a 3×3 (large knobs) up to a 28×28 (tiny but
  legible) preview without any per-grid tuning.
- Reusing `react-native-svg` (already a dependency) rather than Skia keeps the
  preview a plain SVG over the `Image`, with no new render loop.
