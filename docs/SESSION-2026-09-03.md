## 2. What landed

- **Five new grid sizes**: `12 / 16 / 20 / 25 / 28` added to `GridSize`
  (`types.ts`) and `SUPPORTED_GRID_SIZES` (`constants.ts`). Piece counts now
  run 9 → 784. `cellSizeForGrid` already floors at 28 so the dense grids fit.
- **Select Difficulty** (`difficulty-screen.tsx`): preview enlarged to 340dp;
  black grid lines overlaid at `1/(dim-1)` intervals using `dim = √pieces`
  (so 49 → 7×7); a spacer pushes the carousel picker down.
- **Game header** (`game-screen.tsx`): top row is now the timer (left) and piece
  count `locked/total` (right); the puzzle title is gone. Below it a 5-icon row
  — Back, Hint, Edges, Preview, Pause — each a round `PopSurface` with **no text
  label**, showing a ~1s fading tooltip on tap. The old 4-button labelled
  toolbar (and the now-unused shuffle affordance) was removed.
- **Tray scrollbar** (`puzzle-board.tsx`, `board-fx.ts`): replaced the 10dp
  pillow slider with a long rounded-rectangle track (24dp tall, 12dp radius,
  thin border) with arrow buttons at each end and a draggable pill between them.
  The pill's travel is bounded to the space between the arrows, and dragging
  maps through the same constrained travel. Tap zones for the arrows step the
  tray by ~a quarter viewport.
- **Boundary bug** (`tray-geometry.ts`, `puzzle-board.tsx`): new
  `clampPieceToBoard` keeps a released piece's *full silhouette* (tabs included)
  inside `[0, boardSize]`, so edge/corner pieces can no longer hang off the
  frame. `releaseGeometry` now carries each piece's width/height.

## 3. Design tradeoff (resolved)

The 24dp track is 14dp taller than the old 10dp slider, which shrank the largest
(10×10/12×12) board. Chosen resolution: **tighten the slider gap** (16 → 2) so
the tray's total height — and therefore board size — is unchanged. The scrollbar
is now a self-contained bordered control, so it reads as distinct even flush
under the tray rows. `tray-fit.test.ts` still passes its 98%-of-ideal guard.
